Running the website

Everything you need to approve an event, fix a mistake, read a message, or change how the site looks. Nothing here can break the site.

What you can do

  1. Sign in — once per device
  2. Approve an event someone sent in
  3. Fix or change an event
  4. Take an event off the site
  5. Read messages from the Contact form
  6. Change how the site looks
  7. Where things go — and who gets told

Sign in

There is one page where all of this happens. It isn't linked from the menu, so nobody finds it by accident — you go to it directly.

  1. Go to www.earlymusicsa.org/admin.html

    Bookmark it. That's the only address you need.

  2. Paste in the admin password and tick Keep me signed in on this device

    Then you won't have to do it again on that computer or iPad.

  3. You'll see four tabs across the top. Those are the four things you can do.
You both have the same access

There's one password and you share it. Whatever one of you can do, the other can do — approving, editing, hiding, all of it. So if one of you is not up to it on a given day, the other can simply do it instead, and nothing has to be handed over.

Getting the password

Ask whoever set the site up for it — it is not written down in this guide on purpose. Treat it like a house key: it's fine on your own devices, but don't email it or send it in a text.

Approve an event someone sent in

When somebody fills in the Submit Your Event form, the event does not go on the site straight away. It waits for one of you to look at it. That's what the first tab is for.

  1. Open the Events awaiting review tab

    The number beside it is how many are waiting. If it says 0, there's nothing to do.

  2. Read the event

    You'll see everything the person typed — the date, the venue, who's performing, ticket prices, and their own name and email in case you need to ask them something.

  3. Press Approve and publish

    The event appears on the site within a few seconds. You don't need to do anything else.

If it's spam or clearly not an early music concert, press Reject instead. Nothing is sent to the person either way — approving or rejecting is silent.

Read anything flagged

Some submissions arrive with a red note saying they look like spam. That's a guess, not a verdict — a real concert can be flagged by mistake. Read it before you decide.

Fix or change an event

Any event on the site can be changed — including the hundreds that came across from the old website. A wrong time, a misspelled name, a venue that moved. Both of you have exactly the same access here.

  1. Open the Edit events tab
  2. Type in the search box to find it

    You can search by the event name, the venue, who's presenting it, or a date like 2024-11 for November 2024.

  3. Press Edit beside the one you want
  4. Change whatever needs changing, then press Save and rebuild

    The site updates within a few seconds. You can change the name, date and time, description, performers, venue and address, who's presenting, ticket information, the website link, the picture, and the colour it shows in on the calendar.

You cannot lose anything

Your changes are kept separately from the original listing — the original is never overwritten. There's a button on every event called Undo all edits to this event, and it puts the event back exactly as it was, no matter how long ago you changed it or how many times.

So if you're not sure whether to touch something: touch it. It's reversible.

Two small things worth knowing. Boxes you don't touch keep following the original listing, so you only ever change what you actually typed in. And renaming an event doesn't break links people already have — the web address stays the same.

Writing a description

Just type normally. Leave a blank line between paragraphs and it will come out as paragraphs on the page. You don't need to know any code.

Take an event off the site

Sometimes a concert is cancelled, or something was posted that shouldn't have been. You don't delete it — you hide it.

  1. Find the event in Edit events and press Edit
  2. Tick Hide this event from the site at the bottom
  3. Press Save and rebuild

    It disappears from the listings, the calendar and its own page within a few seconds.

Untick the same box to bring it back. Nothing was ever thrown away.

Read messages from the Contact form

When somebody writes in through the Contact Us page, their message lands in the second tab.

  1. Open the Messages tab
  2. Read the message, and press Reply by email to answer it

    That opens your normal email program with their address already filled in. You reply as you would to anyone.

  3. Press Mark as dealt with so it stops showing

    This only tidies your list. It doesn't send the person anything.

Change how the site looks

The fourth tab, Style, holds the site's design — colours, type sizes, spacing — as a list of single settings you can adjust.

  • Colours have a little swatch you click to open a colour picker.
  • Changes preview on the page as you type, so you can see them before committing.
  • Save changes makes them permanent, and they follow you between your computer, phone and iPad.
  • Undo my unsaved edits throws away anything you haven't saved yet.
It can't be broken from here

Every setting is a single design value — a colour, a size, a spacing. There's nothing on that tab that can break the layout or take the site down. Have a play.

Where things go, and who gets told

Short version: you don't have to remember anything. Here's what happens when somebody uses one of the forms.

You'll both get an email

When somebody submits an event or writes in through the Contact page, you are both emailed straight away — you don't have to remember to check anything.

The email has the whole thing in it: the event's date, venue and who sent it, or the message and the person's address. So you can read it on your phone and decide whether it needs doing now or can wait. There's a link at the bottom that takes you to the page where you approve it.

Two things worth knowing about those emails. They're a convenience, not the record — everything is still safely in the list on the admin page, so if an email goes astray or gets swept into junk, nothing is lost. And they go out silently: the person who submitted the event isn't told anything, either when it arrives or when you approve it.

Whoever should receive them can be changed at any time — one of you, both of you, or somebody else entirely.

What happens to your own email address

Nothing on the site publishes it. Contact messages arrive with the sender's address so you can reply to them, and that's the only email the site handles at all. Submitters' names and addresses are stored privately for you to see in the admin page — they never appear on the public site.

If something looks wrong

  • An edit didn't appear. Give it ten seconds and refresh the page — the site rebuilds itself after each save.
  • You've been signed out. The password changed, or you're on a device where you didn't tick "keep me signed in". Sign in again.
  • Anything else. Nothing you do in the admin page can take the site down or lose the events, so it can always wait until whoever set the site up can look at it.
